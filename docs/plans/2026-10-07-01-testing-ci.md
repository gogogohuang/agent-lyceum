# 測試與 CI 實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 讓 `plugins/status-monitor` 的純邏輯測試與型別檢查在 CI 執行，並自動檢查 npm 發佈內容。

**Architecture:** `summary.ts` 只 import 型別、`summary.test.ts` 只用 `expect`/`test`，所以用 vitest alias 把 `claude-code/testing` 指到 vitest 本身即可執行（已實測 9 個測試通過）。`register.tsx` 需要真正的 mod runtime，仍不測。

**Tech Stack:** Vitest、TypeScript、Node 腳本、GitHub Actions。

**Spec:** `docs/specs/01-testing-ci.md`

## 與 spec 的差異（已驗證）

- spec 要求 `tsc -p plugins/status-monitor/tsconfig.json`。**做不到**：該 tsconfig 繼承 `.claude-plugin/types/tsconfig.json`，那個資料夾由 Claude Code 產生且被 `.gitignore` 排除，CI 上不存在。改為只型別檢查 `summary.ts`、`summary.test.ts` 與 `types/index.d.ts`（已實測可通過，含 `noUncheckedIndexedAccess`）。`register.tsx` 不在 CI 型別檢查範圍。
- `npm pack --dry-run` 目前輸出 56 個檔案，沒有 `.map`，且包含 `README.zh-TW.md`；白名單據此制定。

## Global Constraints

- Node >=20，macOS 與 Linux。
- 不新增依賴。
- 不改動 `summary.ts`、`summary.test.ts` 的內容。

### Task 1: plugin 純邏輯測試納入 vitest

**Files:**
- Create: `test/shims/claude-code-testing.ts`
- Modify: `vitest.config.ts`

**Interfaces:**
- Produces: vitest 解析 `claude-code/testing` 為 `test/shims/claude-code-testing.ts`；檔名符合 `plugins/**/*.mod.test.ts` 的測試仍被排除。

- [ ] **Step 1: 確認目前不會跑 plugin 測試**

Run: `npx vitest run plugins 2>&1 | tail -5`
Expected: `No test files found`

- [ ] **Step 2: 建立 shim**

`test/shims/claude-code-testing.ts`：

```ts
// Stands in for Claude Code's `claude-code/testing` so the mod's pure-logic tests run under vitest.
export { expect, test } from 'vitest'
```

- [ ] **Step 3: 改 `vitest.config.ts`**

整個檔案換成：

```ts
import { fileURLToPath } from 'node:url'
import { defineConfig } from 'vitest/config'

// plugins/ tests import `claude-code/testing`, which only exists inside Claude Code; map it to vitest.
// Tests that need the real mod runtime must be named *.mod.test.ts so they stay out of this run.
export default defineConfig({
  resolve: {
    alias: { 'claude-code/testing': fileURLToPath(new URL('./test/shims/claude-code-testing.ts', import.meta.url)) },
  },
  test: { exclude: ['**/node_modules/**', '**/dist/**', 'plugins/**/*.mod.test.ts'] },
})
```

- [ ] **Step 4: 執行 plugin 測試**

Run: `npx vitest run plugins`
Expected: `summary.test.ts (9 tests)` 全 PASS

- [ ] **Step 5: 證明測試真的在守邏輯**

暫時把 `plugins/status-monitor/hooks/summary.ts` 內 `padStart(2, '0')` 改成 `padStart(3, '0')`（`elapsed` 有測試涵蓋；`clip` 目前沒有測試，改它不會失敗）。
Run: `npx vitest run plugins`
Expected: 1 個測試 FAIL（`elapsed formats`）。確認後 `git checkout plugins/status-monitor/hooks/summary.ts`。

- [ ] **Step 6: 跑全部測試**

Run: `npm test`
Expected: 21 個測試檔、219 個測試 PASS（原 20 檔 210 測試 + plugin 1 檔 9 測試）

```bash

git commit -m "test: run the status-monitor mod's pure-logic tests under vitest"
```

### Task 3: 發佈內容檢查

**Files:**
- Create: `scripts/check-pack.mjs`
- Modify: `package.json`（scripts）

**Interfaces:**
- Produces: `npm run check:pack`；通過時印 `pack ok: <n> files`，失敗時 exit 1 並列出多餘檔案。

- [ ] **Step 1: 建立腳本**

`scripts/check-pack.mjs`：

```js
// Fails when the npm tarball holds anything but the built CLI, package.json, the READMEs and the LICENSE.
import { execFileSync } from 'node:child_process'

const out = execFileSync('npm', ['pack', '--dry-run', '--json', '--ignore-scripts'], { encoding: 'utf8' })
const files = JSON.parse(out)[0].files.map((f) => f.path)
const allowed = /^(dist\/.+\.(js|d\.ts)|package\.json|README(\.zh-TW)?\.md|LICENSE)$/

const extra = files.filter((p) => !allowed.test(p))
if (extra.length) {
  console.error(`pack has files that should not be published:\n${extra.map((p) => `  ${p}`).join('\n')}`)
  process.exit(1)
}
if (!files.includes('dist/cli.js')) {
  console.error('pack is missing dist/cli.js (run `npm run build` first)')
  process.exit(1)
}
console.log(`pack ok: ${files.length} files`)
```

- [ ] **Step 2: 加 script**

`package.json` 的 `scripts` 新增：

```json
    "check:pack": "node scripts/check-pack.mjs",
```

- [ ] **Step 3: 執行（應通過）**

Run: `npm run build && npm run check:pack`
Expected: `pack ok: 56 files`

- [ ] **Step 4: 證明會失敗**

Run: `cp package.json package.json.bak && npm pkg set 'files[3]=test' && npm run check:pack; echo exit=$?; mv package.json.bak package.json`
Expected: 列出 `test/...` 檔案、`exit=1`；最後 `git diff package.json` 只剩 Step 2 的 script 變更。

- [ ] **Step 5: Commit**

```bash
git add scripts/check-pack.mjs package.json
git commit -m "ci: verify the npm tarball contents"
```
